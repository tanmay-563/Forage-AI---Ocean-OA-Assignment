# Synthetic marine spare specifications

## Hydraulic filter elements
- Product code HFE-220 uses a 10-micron cellulose element rated for 220 litres per minute at 25 bar.
- Product code HFE-220X uses a 10-micron glass-fibre element rated for 220 litres per minute at 30 bar.
- HFE-220 and HFE-220X have different seal kits and are not interchangeable without Chief Engineer approval.
- Product code HFE-90 uses a 25-micron cellulose element rated for 90 litres per minute at 16 bar.
- Filter element dimensions and port thread must be checked against the vessel drawing before purchase.

## Pump and gasket parts
- Product code PSP-40 is a mechanical seal kit for the Pelagic 40-series seawater pump with a 40 millimetre shaft.
- Product code PSP-60 is a mechanical seal kit for the Pelagic 60-series seawater pump with a 60 millimetre shaft.
- The two pump seal kits are not interchangeable because the shaft diameter differs.
- Product code GSK-DN50 is a DN50 compressed-fibre gasket kit rated for 10 bar at temperatures up to 120 degrees Celsius.
- Product code GSK-DN80 is a DN80 spiral-wound gasket kit rated for 40 bar at temperatures up to 250 degrees Celsius.
- Gasket material must be checked for fluid compatibility by the vessel engineering team.

## Electrical and deck equipment
- Product code LED-24 is a 24-volt DC navigation lamp rated IP67 for exterior marine use.
- Product code LED-230 is a 230-volt AC engine-room inspection lamp rated IP54 for indoor use.
- The two lighting products have different voltage and ingress-protection ratings and are not substitutes.
- Product code SHK-12 is a 12 millimetre stainless-steel bow shackle with a 1.5-tonne working load limit.
- Product code SHK-16 is a 16 millimetre galvanized-steel bow shackle with a 2-tonne working load limit.
- A shackle's working load limit must not be exceeded, and lifting plans must follow vessel safety procedures.
